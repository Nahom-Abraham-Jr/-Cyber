# ደህንነት (Dehinet) — Cybersecurity Platform

Modern cybersecurity awareness app (Next.js + Tailwind). English & Amharic.

## Live site

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FNahom-Abraham-Jr%2F-Cyber&project-name=dehinet-cyber&framework=nextjs)

After deploy, your site will be at **https://dehinet-cyber.vercel.app**

> Use project name **`dehinet-cyber`** (not `-cyber`). Repo names starting with `-` break some Vercel URLs.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
